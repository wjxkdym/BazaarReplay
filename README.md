# Bazaar Replay 1.8.0-beta.2 · 受限测试版

The Bazaar 游戏内操作录像插件：自动记录操作、固定间隔回放、按天/小时直接定位、按小时截取片段、查看录像末尾装备与技能。

**这是预发布测试版，尚未完成本最终构建的完整跨版本回归。曾出现一次尚未查明原因的退出崩溃；后续正常退出不等于已修复。不建议将它当作稳定版。**

## 下载与安装

[打开 GitHub 下载页](https://github.com/wjxkdym/BazaarReplay/releases/tag/v1.8.0-beta.2)

完整源代码作为 `source.zip` 随 Release 提供；请阅读随包安装说明和验证范围。

- 普通用户下载 `BazaarReplay-1.8.0-beta.2-windows.zip`；源码在 `source.zip`。
- 校验文件：`SHA256-1.8.0-beta.2.txt`。
- 适用 Windows Steam Build **26443971 / 1.0.13082**，需要事先安装 BepInEx 5。本包不包含游戏、BepInEx 或其他插件。
- 正常保存片段并关闭游戏，完整解压安装包，然后按包内说明运行 `install.ps1`。安装器会备份插件旧文件；录像、收藏与设置保留。
- 安装器会检查游戏及可选 BazaarPlusPlus 的精确构建。检查失败请勿强行覆盖。回退使用包内 `restore.ps1`。

## 本次调整

- 改善回放清理、文字资源和动画生命周期处理。
- 旧阵容说明中未记录的属性显示“未记录”，不再误显示为 0；真实 0 值保留，去除相邻重复效果词。
- 录像库提前显示跨版本测试限制；过期测试会话需要新的有效隔离授权。
- 加强安装校验、备份和可重复打包。

## 验证与限制

- 286 项功能检查、49 项安装检查通过；源码包重建的两个 DLL 与本包一致。
- 最终 DLL 已实测启动、末尾装备技能预览、缺失属性提示及一次正常退出。
- 前身研究版通过的 21 场完整录像、两战斗片段和原生重放/定位测试，**不能替代本最终测试包尚未完成的完整回归**。
- 普通同版本回放仍保留严格版本检查。跨版本实验只接受三份事先审查的原始录像哈希；这些私人样本不分发。其他旧录像只能只读浏览，不能承诺公众已有旧录像均可播放。
- 跨版本实验需要临时游戏网络隔离及 Windows 管理员确认；测试中游戏在线功能暂不可用。云端功能仍为受邀测试，安装包不含授权密钥。
- 当前客户端提供的名称、卡图和说明可能与历史平衡不同。已记录属性与未知字段明确区分。
- 不进入自动更新渠道。已知偶发退出崩溃、重复释放警告及一般化兼容审查仍待继续处理。

本项目为非官方插件，与 The Bazaar 官方无隶属关系。安装包和源码包不包含私人录像、游戏资源、原始测试日志或账号令牌。
